A cloud-based platform for discovering employment, learnership, internship and skills-development opportunities in South Africa.

Stage 2:

Stage 4:

Stage 5:
Expose Lambda functions through API Gateway

Stage 6:
Connect the frontend to the API

Stage 7:
Configure AMI permissions and CloudWatch monitoring
